# appraise-6945af
Appraise — built on Usernode Social Vibecoding

## What it does

Appraise lets a community run **voting rounds** over the apps built on the platform:

- Create rounds with configurable **vote-distribution rules** (concentrate votes or one-per-app)
- Optional **self-vote** and **testers-only** restrictions per round
- Cast ballots while a round is open; results stay hidden from non-admins until it closes
- **Live tally / final results** pages, shareable publicly
- Public **leaderboard and builders APIs** for round progress and per-app contributor stats
